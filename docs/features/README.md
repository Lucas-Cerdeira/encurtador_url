# Features

Este diretório contém documentação de features planejadas, em desenvolvimento e implementadas.

## Estrutura

- `propostas/` - Features propostas para discussão
- `em-desenvolvimento/` - Features que estão sendo implementadas
- `implementadas/` - Features já concluídas

## Formato Sugerido

Cada feature deve ter um arquivo com:

```markdown
# Nome da Feature

## Descrição
Breve descrição do que a feature faz

## Objetivo
Por que essa feature é necessária

## Requisitos
- Requisito 1
- Requisito 2

## Implementação
Como foi ou será implementada

## Status
- [ ] Proposta
- [ ] Em desenvolvimento
- [x] Implementada
```
