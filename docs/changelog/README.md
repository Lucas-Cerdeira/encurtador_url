# Changelog

Este diretório contém o histórico de mudanças do projeto.

## Estrutura

- Os changelogs são organizados por data ou versão
- Cada arquivo representa uma mudança significativa ou conjunto de mudanças
- Use o formato: `YYYY-MM-DD-descricao.md` ou `vX.X.X.md`

## Formato Sugerido

```markdown
# [Data ou Versão] - Descrição

## Adicionado
- Nova funcionalidade X

## Modificado
- Alteração em Y

## Corrigido
- Bug Z resolvido

## Removido
- Funcionalidade W removida
```
